# 汽水音乐「看广告领免费听时长」全自动脚本

> `soda_music_farm.py` —— 把手工「看广告 → 领取成功 → 领奖励 → 下一轮」的重复流程固化成一个**不依赖 AI、可独立运行**的自动化脚本。
>
> 实测成果：脚本自主运行约 20 分钟，把「免费听时长」从 **20 分钟累积到 6 天**（第 2~6 天奖励全部自动领取）。

---

## 一、它做什么

自动完成汽水音乐（`com.luna.music`）福利中心的领时长循环：

```
启动 App → 福利 tab → 福利中心 → 点「领时长」
   ↓
广告播放（右上角「N秒后可领取奖励」倒计时，每 20s 检测一次）
   ↓
倒计时结束 → 右上角「领取成功 ×」→ 点 × 关广告
   ↓
弹窗「再看N个视频得xx免费听」→ 点「领取奖励」→ 继续下一轮广告
   ↓
（链路结束只剩「坚持退出」→ 点它回福利中心，可再开一轮）
```

中途所有岔路（直播间落地页、推荐弹窗、签到弹窗、优惠券弹窗、互动要求等）都已有对应规则处理。

## 二、运行原理（三层架构）

| 层 | 作用 | 实现 |
|---|---|---|
| **控制层** | 操作模拟器 | 蓝叠自带 `hd-adb`：截图回传、`input tap` 点击、`input keyevent 4` 返回 |
| **识别层** | 「认字」替代 AI 视觉 | 宿主机 macOS **Vision 框架中文 OCR**，把截图转成「文本 + 像素坐标」列表 |
| **决策层** | 状态机 | 按优先级匹配 OCR 文本，决定下一步动作；带熔断与卡死恢复 |

**为什么不用 `uiautomator dump`**：广告视频播放时它拿不到 idle 状态，报 `could not get idle state`，实测不可靠。OCR 方案稳定得多。

**关键环境约束**：蓝叠的 `adbd` 有命令白名单，直接跑任意 shell 命令会报 `error: closed`，必须用 `getprop ro.build.version.sdk; <命令>` 拼接绕过（脚本已内置）。

## 三、环境要求

- **macOS**（依赖系统自带 Vision OCR 框架）
- **BlueStacks Air**（蓝叠模拟器），已启动并开启 ADB 调试
- **Python 3**：建议创建一个独立虚拟环境（venv）来安装依赖，后文以 `<venv>` 指代该环境目录
- 该 venv 需装有：`pyobjc-framework-Vision`、`pyobjc-framework-CoreGraphics`、`pillow`

## 四、快速开始（操作设置说明）

### 步骤 1：确认模拟器与网络

1. 打开 **BlueStacks Air**，进入汽水音乐并能正常联网（若之前抓过包，注意残留代理会导致断网，见「故障排查」）。
2. 确认 ADB 可用：
   ```bash
   /Applications/BlueStacks.app/Contents/MacOS/hd-adb devices
   ```
   输出里应能看到 `emulator-5554    device`。

> ⚠️ **不要与 Android SDK 的 `adb` 混用**（`~/Library/Android/sdk/platform-tools/adb`）。两套 adb server 会互相抢占通道导致 `error: closed`。若混用过，先执行：
> ```bash
> ~/Library/Android/sdk/platform-tools/adb kill-server
> ```

### 步骤 2：启动脚本

在**你自己的终端**里运行（这样会话结束脚本也不会中断）：

```bash
cd <脚本所在目录>
<venv>/bin/python3 ./soda_music_farm.py --rounds 100 --poll 20 --shots ./shots/farm_run
```

启动后脚本会自动 `launch` 汽水音乐，并开始循环领时长。

### 步骤 3：观察运行

- 终端会实时打印每一步动作，例如：
  ```
  [09:29:25] 🎁 奖励弹窗: 领取奖励
  [09:29:37] ⏳ 广告倒计时中: 31秒后可领取奖励
  [09:30:25] ✅ 领取成功 → 关闭广告
  ```
- `--shots` 目录会归档每步截图（`HHMMSS_序号_标签.png`），方便事后排查。

### 停止

- 终端里按 **`Ctrl+C`** 立即停止；
- 期间**不要手动操作模拟器**，避免与脚本抢点击。

## 五、参数说明

| 参数 | 默认 | 说明 |
|---|---|---|
| `--rounds N` | 20 | 最大轮数。链路上限，防止无限跑；跑满或连续无动作即结束 |
| `--poll N` | 20 | 广告倒计时检测间隔（秒）。即「每 20 秒截图检测一次」 |
| `--shots DIR` | 空 | 截图归档目录；不填则不存图。建议开启便于排障 |

示例（快速试跑 3 轮、检测间隔 15 秒、存图）：

```bash
$PY soda_music_farm.py --rounds 3 --poll 15 --shots ./shots/test
```

## 六、状态机识别规则（脚本核心逻辑）

`step()` 按**从高到低**的优先级匹配，命中即执行并返回：

| 优先级 | 屏幕特征（OCR 文本） | 动作 | 备注 |
|---|---|---|---|
| 1 | 「继续互动 / 继续观看 / 去互动 / 浏览领取」(≤8字) | 点击它 | 广告要求互动，否则倒计时冻结 |
| 2 | 含「后进入直播间」且含「取消」(≤4字) | 点「取消」 | 拦截广告自动跳直播间 |
| 3 | 「领取奖励」(限屏中部 y 880~1160、≤8字、排除"成功/已领/秒") | 点它 → 下一轮广告 | **必须先于「领取成功」**，否则会被弹窗挡住 |
| 4 | 含「可领取奖励」且含「秒」且不含「成功」 | 等 `--poll` 秒 | 倒计时中；文本连续 3 次不变 → 判卡死按返回 |
| 5 | 「领取成功」(≤10字，y < 200) | 点徽章右侧 62px 的 × | 关广告 |
| 6 | 「为你精选以下直播 / 为你精选」 | 点弹窗右上 × | 推荐弹窗 |
| 7 | 「恭喜获得/后过期」且「立即使用/点击使用」 | 点底部小 × | 优惠券弹窗，**绝不点「使用」** |
| 8 | 「进入直播间/更多直播/说点什么」等落地页特征（且无「坚持退出」、无奖励按钮） | 停 15s（计观看时长）→ 返回 | 直播间落地页 |
| 9 | 「坚持退出」（且无奖励按钮） | 点它 | 链条结束，回福利中心 |
| 10 | 「签到7天领 / 每天连续签到」 | 点弹窗关闭位置 | 签到弹窗 |
| 11 | 「领时长」 | 点它 | 福利中心入口 |
| 12 | 「免费听时长 / 金币收益」且无「领时长」 | 等待 | 福利中心暂无可领 |
| 13 | 「发现 / 听抖音」 | 点底部「福利」tab | 主界面 |

**安全保护机制**：

- **熔断**：同一动作连续 6 次（`_guard`）→ 自动按返回键打破僵局；
- **倒计时卡死恢复**：同一倒计时文本连续 3 次不变 → 按返回键尝试恢复；
- **禁区**：脚本**永不**主动点击 `跳转微信 / 立即使用 / 点击使用 / 查看详情 / 立即下载 / 退出不看了`（定义在 `FORBIDDEN`）；
- **闲置退出**：75 秒内无任何可执行动作 → 判定结束当前轮。

## 七、故障排查

| 现象 | 原因与处理 |
|---|---|
| `未找到模拟器` | 蓝叠未启动 / ADB 调试未开。用 `hd-adb devices` 确认能看到 `device` |
| 命令报 `error: closed` | ①与 SDK adb 混用冲突 → `platform-tools/adb kill-server`；②脚本已内置白名单绕过，若仍报错请确认用的是 `hd-adb` |
| App 显示「网络异常」 | 残留全局代理。清除：`hd-adb shell "settings put global http_proxy :0"` |
| OCR 识别到错字（如把「秒后」认成「竹秒居」） | 已用模糊匹配容错；若出现新的长串误匹配，参考下方「扩展」加区域/长度约束 |
| 卡在某个界面反复点同一处 | 翻 `--shots` 里的最新截图定位界面，在 `step()` 中补一条规则；熔断与卡死恢复会兜底 |
| 想临时停手 | 终端 `Ctrl+C` |

**恢复现场**（脚本停后模拟器停在广告页想手动退出）：连按返回键
```bash
/Applications/BlueStacks.app/Contents/MacOS/hd-adb -s emulator-5554 shell \
  "getprop ro.build.version.sdk; input keyevent 4"
```

## 八、维护与扩展

### 坐标兜底

`FALLBACK` 字典存放 1080×1920 分辨率下的兜底坐标，仅当 OCR 找不到元素时使用。若换机型/分辨率需同步调整（建议优先依赖 OCR 坐标，兜底坐标越少越好）。

### 新增一条规则

在 `Farm.step()` 里按优先级插一段即可，例如：

```python
if e.has("你的新弹窗关键词"):
    log("  处理新弹窗")
    self.adb.tap(*fb["xxx_close"])
    time.sleep(3)
    return True
```

要点：
- 命中即 `return True`（表示有动作），否则 `return False`；
- 弹窗类规则要排在广告页状态**之前**（弹窗浮在广告之上）；
- 匹配长文案时用 `region=` 限定屏幕区域、`max_len=` 限定字数，避免 OCR 把横幅连成长串误匹配。

### 识别层复用

`ocr(png)` 函数与 `Eye` 类可独立用于任何「截图 → 中文文字+坐标」场景。
